# Clean-Room Originality Check

ACCORDANT was designed around a different product problem: bilateral milestone acceptance for public evidence-verifiable work.

Before submission, perform a hostile comparison against any reference repo used during research.

The final product must remain independently recognizable through:

- engagement/milestone/criterion/attempt terminology
- two-party proposal and acceptance loop
- `MET` / `NOT_MET` / `UNVERIFIABLE` criterion decisions
- `ACCEPTED` / `REVISION_REQUIRED` / `INCONCLUSIVE` product outcomes
- criterion-bound evidence submission
- task-oriented delivery workspace UX
- original routes
- original page structure and copy
- original storage and method design
- no escrow, token, payout, authority registry, binary-event charter, case adjudication, prediction market, or generic arbitration layer

If the implementation starts drifting toward a reference product’s information architecture or vocabulary, redesign that surface before submission.
